# MouthLife: The Plaque Dimension

A progressive stylized-3D browser arcade adventure (`TypeScript` + `Vite` + `Three.js`) where real dental-care habits unlock increasingly bizarre microscopic worlds — without punitive streak tracking.

- **Design & Architecture Spec:** [`docs/GDD_AND_ARCHITECTURE.md`](docs/GDD_AND_ARCHITECTURE.md)
- **First Playable Target:** Level 1 — *Plaque City* (Toothbrush, Floss Pick, Mouthwash + 2-Minute Brush-Along Daily Mission)
